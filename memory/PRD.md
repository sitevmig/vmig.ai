# PRD — Лендинг «Вмиг» (vmig.ai)

## Исходная задача
«Сделай несложный, простой, но практичный сайт лендинг для компании, информацию возьми отсюда (презентация Вмиг.pptx). Главное отрази цены на подписки и контакты для связи.»

Выборы пользователя: стиль — как в презентации; заявки с формы — отправлять на почту; админка не нужна.

## Архитектура
- Frontend: React 19 + Tailwind + framer-motion + lenis (плавный скролл). Одностраничный лендинг, компоненты в `/app/frontend/src/components/landing/`.
- Backend: FastAPI, `POST /api/leads` — сохраняет заявку в MongoDB (`leads`) и отправляет письмо на vmig.ai@mail.ru через Emergent managed Resend (прокси integrations.emergentagent.com, ключ EMERGENT_EMAIL_KEY в backend/.env). Rate-limit 5 заявок / 10 мин с IP.
- Дизайн-система: `/app/design_guidelines.json` — тёмная тема #070709, акцент #E11D48, шрифты Unbounded/Manrope/JetBrains Mono.

## Персоны
- Владелец малого бизнеса / блогер — хочет дешёвые регулярные ролики.
- Продавец маркетплейсов — нужны карточки-видео.
- Агентство — объёмы для ежедневного постинга.

## Ключевые требования (статичные)
- Цены: Старт 1 990 ₽, Про 5 500 ₽ (популярный), Макс 11 900 ₽, Бизнес 37 900 ₽/мес; доп. пакеты 30/60/90 сек — 690/1 290/1 790 ₽. 1 миг = 1 сек видео с аватаром.
- Контакты: vmig.ai@mail.ru.
- Оффер: первые 5 роликов бесплатно, без карты.

## Реализовано (09.07.2026)
- Полный лендинг: hero с кинетическим построчным появлением и параллакс-телефоном, бегущая строка форматов, секции «Проблема», «Как работает», «3 формата» (ссылки на примеры Google Drive), «Тарифы» (4 карточки + доп. пакеты), «5 роликов бесплатно», контактная форма + футер.
- Форма: имя, контакт, выбор тарифа (подставляется при клике на тариф), комментарий → письмо на vmig.ai@mail.ru + запись в БД; тосты sonner, mailto-фолбэк при ошибке.
- Адаптив, мобильное меню, data-testid на всех интерактивных элементах.

## Реализовано (09.07.2026, итерация 2)
- Калькулятор мигов в секции тарифов: слайдер «роликов в месяц» (1–80) + выбор длины (15/30/60 сек) → расчёт нужных мигов, подсветка подходящего тарифа бейджем «Подходит вам», цена за ролик, CTA сразу ведёт в форму с подставленным тарифом.
- Видео-примеры встроены на страницу: клик по карточке формата открывает модалку с реальными вертикальными роликами из Google Drive (плееры iframe /preview), 3 ролика с аватаром + 2 слайдшоу; ссылка на полную папку сохранена в модалке.

## Реализовано (09.07.2026, итерация 3 — правки по фидбеку)
- Дизайн приведён к реальному бренду из презентации: фирменный оранжевый (#E8692F) на тёплом графите (#141210/#201D1A, тёплые серые stone), логотип-«искра» из файла презентации (/public/logo.png) в шапке и футере, название без «.ai».
- Hero: убрана строка «ИИ-платформа видеоконтента — vmig.ai»; фото смартфона с девушкой заменено на реальный ролик клиента (ex2.mp4, автоплей в рамке телефона с постером).
- «Как работает»: шаг 1 — «Введите свой текст или используйте автоматический промпт. Загрузите фото и видео для использования в ролике»; шаги переименованы в «Платформа сгенерирует» и «Публикуйте через автопостинг»; ячейки фич выровнены по высоте (h-full).
- Форматы: раздел «Ролики для маркетплейсов» удалён, осталось 2 формата; ссылки на Google Drive убраны полностью — в модалке проигрываются загруженные клиентом видео (/public/videos/ex1.mp4, ex2.mp4, конвертированы из MOV в H.264) с постерами-кадрами из самих роликов.
- Фикс: бейджи «Популярный» и «Подходит вам» на карточке Про больше не перекрываются.
